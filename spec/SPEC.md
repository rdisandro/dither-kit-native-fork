# Display-list contract

The [Rust encoder](../rust/dither-ir/src/encode.rs) and [reference VM](../rust/dither-ir/src/vm.rs) define the program and per-pixel behavior. See [PLAN.md](../PLAN.md#program-format-see-rustdither-irsrcprogramrs) for the opcode argument table and enum IDs.

Programs are flat arrays of IEEE-754 binary32 values:

```text
[P, opcode, total_length, arguments..., opcode, total_length, arguments..., tables...]
```

`P` counts the floats occupied by operations, excluding the initial header and tables. The first operation starts at index 1. Each operation length includes its opcode and length. Table offsets are relative to `1 + P`. `NONE = -1e9` marks absent column geometry.

Operations paint in order and overwrite earlier pixels. The first BLOOM operation divides base content from overlay content. Base operations are evaluated before bloom; overlay operations are evaluated afterward. With no BLOOM, all operations belong to the base list. Radius zero is a valid overlay delimiter.

Coordinates use a top-left origin and one unit per dither pixel. Avatar programs always describe an 8 by 8 grid. Constant RGBA values are in the range 0 through 255; tone colors store hue and chroma and are shaded per pixel. The base pass has straight alpha. Compositing output is premultiplied; golden-test output is straight alpha.

## Numerical parity

- Round half away from zero with `sign(v) * floor(abs(v) + 0.5)`.
- Integer modulo used by the interpreter is Euclidean, including negative coordinates.
- Hash arithmetic wraps in unsigned 32-bit integers. Preserve the bits when converting signed values. Convert hashes to `[0,1)` with `float(h) / 4294967296.0`.
- Use repeated squaring for integer powers, including exponent 12.
- OKLCH gamut reduction subtracts 0.005 chroma per iteration, without replacing the loop with multiplication.
- Pie angles use `atan2(dx, -dy)`, wrapped into `[0, tau)`.
- Closed-form Bresenham computes the minor offset with integer division: `(2*k*a_minor + a_major) / (2*a_major)`, where `k` is distance along the major axis. Reference tests exhaustively compare it with iterative Bresenham.
- Bloom visits rings in ascending distance, then `oy = -d...d`, then `ox = -d...d`, excluding non-ring coordinates. The first neighbor with alpha greater than 160 wins. Do not search for the brightest neighbor.

## Future-Retro ramps

See [docs/FUTURE-RETRO.md](../docs/FUTURE-RETRO.md) for the design mapping. Interpreter rules:

- A negative chroma names a ramp: `-1` Near AI blue `(3,92,163) (0,145,253) (131,220,255) (250,250,247)`, `-2` ink `(38,38,43) (128,128,136) (193,193,193) (250,250,247)`. Step 0 or any step outside 1–4 is slate `(38,38,43)`.
- Coverage returns a rank `u`: `-1` when uncovered; otherwise `t / k`, where `t` is the matrix threshold and `k` the intensity the threshold is compared against. Solid fill, dot-matrix fill, lines, rims, button edges, meter caps and swatches use the 4×4 Bayer threshold at the pixel (dot matrix: at `(x/2, y/2)`; bar matrix: at `((x−bx0)/2, (h−1−y)/2)`).
- A ramp shade computes `p = clamp(1 + (level − 0.3) × 4, 1, 4)`, `s = floor(p)`, and returns step `min(s + (u < p − s), 4)`. Compute `p − s` exactly as written; do not fold it into another expression.
- Fill 4 (dot matrix) covers `x mod 2 = 0 ∧ y mod 2 = 0 ∧ i > 0.02`. `BAR` with fill 4 lights `(x − bx0) mod 2 = 0 ∧ (h − 1 − y) mod 2 = 0` at level `0.3 + 0.55 s`, with `s = (bottom − y + 1) / max(bottom − ty + 1, 1)`, and paints `(193,193,193,23)` above `ty`. `METER` with fill 4 lights even cells left of the value at `0.3 + 0.55 (x+1)/filled` and paints the rest of the even cells `(193,193,193,23)`. A ramp `METER` with any other fill paints that faint grid as its track.
- Fields 5–8 use absolute cell coordinates scaled by `0.01875`, the fbm described in the mapping, and `clamp(((v − 0.5) × 1.3 + 0.5) × 1.25, 0, 1)`, without the upstream smoothstep. Their shade level is `0.3 + 0.42 × light`.
- A `BUTTON` with a ramp tone is flat: style 0 fills the step-2 color, lifted 12% toward white (`round(c + (255 − c) × 0.12)` per channel) when density > 0.4; style 1 paints marble on the edge, and everywhere when density > 0; style 2 paints nothing. No sparkles.
- An `AVATAR` hue below zero names a ramp: accent pixels step 3, lit pixels step 2, the rest slate.
- A `BLOOM` op of length 5 whose third argument is 1 paints glow pixels opaque `(3,92,163,255)` instead of fading the neighbor.
